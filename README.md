# Attendance SaaS (نظام الحضور)

Monorepo (npm workspaces): `packages/shared` (محرك النقاط) · `apps/api` (NestJS — التالي) · `apps/web` · `apps/mobile`.

```bash
npm install
npm test          # 79 اختباراً لمحرك النقاط
npm run db:up     # PostgreSQL عبر Docker
```

## التشغيل السريع (3 طرفيات)
المتطلبات: Node.js 20+، Docker Desktop، وتطبيق Expo Go على الجوال.
```bash
npm install                                  # مرة واحدة: يثبّت الـ API والويب والحزمة المشتركة
npm run db:up                                # قاعدة البيانات
cp apps/api/.env.example apps/api/.env       # Windows: copy apps\api\.env.example apps\api\.env  (ثم عدّل JWT_SECRET)
npm run api:setup                            # يولّد Prisma + الجداول + بيانات تجريبية
npm run api                                  # الطرفية 1: الـ API على :3000
cp apps/web/.env.example apps/web/.env.local
npm run web                                  # الطرفية 2: الويب على :3001
```
الجوال: انظر القسم التالي. حسابات التجربة: رمز الشركة `demo` — `hr@demo.test` و`emp@demo.test` — كلمة المرور `ChangeMe!123`.

## تشغيل تطبيق الجوال
مشروع مستقل (ليس ضمن workspaces لاختلاف إصدار React):
```bash
cd apps/mobile && cp .env.example .env   # ضع عنوان الـ API على شبكتك (ليس localhost على الجوال)
npm install && npm start                 # ثم افتحه بتطبيق Expo Go
```
قرار: لا يوجد حضور دون اتصال، لأن وقت السيرفر هو المرجع؛ تسجيل مؤجَّل سيُحتسب بوقت الرفع وليس وقت الحضور الفعلي.
