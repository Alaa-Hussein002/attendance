# برنامج جهاز البصمة (Agent)

يعمل على كمبيوتر داخل شبكة المقر، يقرأ سجلات جهاز ZKTeco كل دقيقة ويرسلها للنظام. لا يغيّر شيئاً على الجهاز.

1. ثبّت Node.js 20+ .
2. من مجلد `apps/agent`: انسخ `.env.example` إلى `.env` وعبّئه (مفتاح الجهاز يظهر مرة واحدة في الويب: الإعدادات ← أجهزة البصمة).
3. `npm install` ثم `npm start`.
4. لتشغيله دائماً (يبدأ مع Windows): `npm i -g pm2 pm2-windows-startup` ثم `pm2 start "npm start" --name bayt-agent` ثم `pm2 save`.

**أول بصمة في اليوم = تسجيل الحضور.** ما بعدها تُسجَّل كمكررة. وإن كان رقم البصمة غير مربوط بموظف يظهر في الويب لتربطه بنقرة.
